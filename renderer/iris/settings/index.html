Your own OpenCode key — optional

Not required: the free models answer without one. A key of your own raises your rate limit. Stored encrypted by this machine's own secret store (DPAPI on Windows, the Keychain on macOS) via Electron safeStorage — never in plain text, and only ever sent to opencode.ai.

The opencode CLI

Checking…
Uses the opencode binary and whatever it is already signed in to. GemAir never sees or stores that sign-in — the CLI keeps it. Slower than the hosted route, and it works offline against a local model.

Install guides

These ship inside GemAir and work offline. Opening one runs it hands-free if you have allowed that below.

Behaviour

Maintain mode only ever watches apps GemAir installed from a guide, and only ever patches a source clone it made itself.

Privacy

Screenshots are held in memory, sent only to the model route you are using, and never written to disk. GemAir Assist does not record audio.
